# ClassHub 3-B - クラス専用学習・情報共有Webアプリケーション

出席番号1番〜40番のアカウント管理、完全匿名ランキング、英単語＆ミゾブルー定期テスト、教材共有、学習掲示板を備えたクラス専用Webアプリケーションです。

## 🚀 GitHub Actions による GitHub Pages 自動公開手順

このリポジトリには、GitHubにプッシュするだけで自動的にビルド＆公開が行われる **GitHub Actions ワークフロー (`.github/workflows/deploy.yml`)** が設定されています。

### 1. GitHubリポジトリへのプッシュ
ローカルまたはお使いの開発環境からコードをGitHubにプッシュします。

```bash
git add .
git commit -m "ClassHub 初期セットアップとGitHub Actions自動デプロイ設定"
git push origin main
```

### 2. GitHub Pagesの設定（初回のみ）
1. GitHubの対象リポジトリ画面を開きます。
2. 上部メニューの **[Settings]** タブをクリックします。
3. 左サイドメニューの **[Pages]** を選択します。
4. **[Build and deployment]** セクションの **Source** ドロップダウンで **`GitHub Actions`** を選択します。

### 3. デプロイの完了確認
- `main` (または `master`) ブランチにコミットがプッシュされると、自動的に GitHub Actions ワークフローが起動します。
- リポジトリの **[Actions]** タブからデプロイ状況を確認できます。
- ビルド完了後、`https://<あなたのGitHubユーザー名>.github.io/<リポジトリ名>/` でWebアプリが全世界に自動公開されます！

## 🛠️ ローカル開発・ビルドコマンド

```bash
# 依存関係のインストール
npm install

# 開発用ローカルサーバーの起動 (ポート 3000)
npm run dev

# 型チェック (TypeScript)
npm run lint

# プロダクションビルド (404.html 自動生成付き)
npm run build
```

## 🔒 プライバシー＆セキュリティ仕様

- **出席番号アカウント**: 1番〜40番対応（本名登録不要）。
- **匿名ランキング**: 全体順位表および成長度表では出席番号・ニックネームを一切非公開化。
- **オンページ印刷・プレビュー**: 定期テスト・教材データはダウンロード不要で画面上直接プレビュー可能。
- **`/edit` 編集ページ**: 定期テスト一覧および小テストの問題文・選択肢・解説の追加・変更が可能。
