# [いちはちさいと (1-8 SITE)] UI Rebranding & Reconstruction Plan

1年8組の学習・情報共有ポータルを「**いちはちさいと**」（英語表記：1-8 SITE）へ改称し、神山まるごと高専の学園祭特設サイト（`2026.marugotosai.jp`）をモデルとした、クリエイティブで活気あふれる**モダン学園祭スタイル（Creative Academic Festival UI）**へとデザイン・レイアウトを再構築します。

---

## User Review & Critical Decisions

> [!IMPORTANT]
> ユーザー様とのヒアリング（Phase 1）で確定した方針に基づき、以下の3点を最優先指針としてUI再構築を実施します。

- **Confirmed Decision 1 (デザインスタイル)**: 神山まるごと高専「まるごと祭」特設サイトをモデルとした、**洗練されたクリエイティブ・モダン学園祭スタイル**（太字の和文タイポグラフィ、フェスティバル感のあるアクセントカラー、クリーンな余白とカード構成）。
- **Confirmed Decision 2 (機能の継承)**: 現在提供されている**全学習機能（出席番号1〜40番のパスワード認証、完全匿名順位・成長度、定期テスト・小テスト、PDF/JPG実物問題用紙ビューア、掲示板、/edit編集機能）を100%保持**したまま、まるごと祭のUIレイアウトへ統合。
- **Confirmed Decision 3 (サイト名・ロゴ表記)**: メインロゴは「**いちはちさいと**」、サブ英字表記は「**1-8 SITE**」として統一配置。

---

## 1. Overview & Core Concept

- **What It Does**: 1年8組の生徒全員が日々の小テスト演習、定期考査の匿名順位確認、過去問・問題用紙のプレビュー、学習相談をワクワクしながら行える、学園祭のように創造的で前向きな学習ポータル。
- **Target Audience**: 1年8組（出席番号1〜40番）の生徒および教員。
- **Key Value**: 従来の事務的な管理画面感を一新し、「つくることは、いきること」「まなぶことは、つながること」という学園祭のエネルギーを取り入れた、見やすく意欲の高まるクラス専用UIを提供。

---

## 2. User Experience & Visual Design

### Visual Identity & Theme (Inspired by marugotosai.jp)
- **Aesthetic Direction**: Creative Modern Academic Festival（クリエイティブ・モダン学園祭スタイル）。
- **Color Palette & Mood (60-30-10 Rule)**:
  - **60% Dominant Canvas**: 清潔感と温かみのあるオフホワイト・フェスティバルペーパー背景 (`#FAF9F6` / `#F8FAFC`)。
  - **30% Structural Surfaces**: クリーンなホワイトカード面、繊細なヘアライン境界線 (`#E2E8F0`)、落ち着いたスレート文字 (`#0F172A`, `#334155`)。
  - **10% Festival Accents**: まるごと祭を象徴するエネルギッシュなアクセントカラー（鮮やかなセルリアンブルー `#0284C7`、新緑のミントエメラルド `#059669`、太陽のアンバーゴールド `#D97706`、祝祭のコーラルレッド `#E11D48`）。
- **Typography & Display Layout**:
  - タイトル・見出し：幾何学的で力強い和文モダンゴシック＋英字アクセント（`font-display`, `Bricolage Grotesque` / `Outfit` / `Plus Jakarta Sans`）。
  - サブコピー：学園祭のキャッチコピー感を持たせた「まなぶ。つくる。ひろがる。」のリズムあるタイポグラフィ。
  - 数値・順位：等幅数字 (`tabular-nums`) による整然とした視認性。

### Key Components & Layout Layout Walkthrough
1. **Top Bar Contract (1行3ゾーン構成)**:
   - **Zone 1 (Brand)**: 「いちはちさいと」ロゴマーク（1-8 SITE アイコン ＋ 太字和文タイトル）。
   - **Zone 2 (Navigation)**: `成績・順位` / `定期テスト` / `教材共有` / `掲示板` / `マイページ` / `問題編集 (/edit)`。まるごと祭スタイルのアクティブハイライト。
   - **Zone 3 (Action)**: 生徒ステータス（出席番号・ニックネーム）＆ログアウトボタン。
2. **Festival Hero & Marquee Strip**:
   - 画面上部に、まるごと祭を想起させるダイナミックなフェスティバルヘッダー。
   - 「1-8 SITE FESTIVAL · 定期考査対策演習中 · 英単語＆ミゾブルー公開中 · 1年8組学習ポータル」のリズミカルなティッカーストリップ。
3. **Tab & Program Showcase Cards**:
   - まるごと祭のタイムテーブル・出展ブースをモチーフにした、見やすく整理されたカードレイアウト。
   - 匿名順位表や問題用紙画像ビューアも、学園祭の展示ポスターのように明快かつ直感的にブラウズ可能。

## 3. Key Product Decisions & Trade-Offs

- **Decision 1: 学園祭ビジュアルと実用学習機能の両立**:
  - *Chosen Approach*: 装飾が学習の邪魔にならないよう、テキストの可読性やクリック領域（44px以上）、数値の並びは厳格に整えつつ、ヘッダー・カード・タグのスタイリングにまるごと祭の躍動感を採用。
  - *Why*: 毎日使う学習システムとしての信頼性と、開いた瞬間のワクワク感を同時に満たすため。
- **Decision 2: 既存の認証・プライバシー管理の維持**:
  - *Chosen Approach*: 出席番号1〜40番、初期パスワード0000、全体順位表での個人情報ゼロ秘匿ルールは一切変更せず完全に保持。
  - *Why*: クラス内の安心して利用できるプライバシー基盤を守るため。

## 5. Implementation Steps & Verification

1. **Branding & Metadata Update**:
   - `metadata.json`, `index.html`, `README.md` のサイト名を「いちはちさいと (1-8 SITE)」に更新。
2. **Theme & Visual System Implementation**:
   - `Navbar.tsx` に「いちはちさいと」ロゴとまるごと祭スタイルのナビゲーションを適用。
   - `FestivalHeroStrip` コンポーネントを導入し、学園祭特設サイトのようなリズミカルなキービジュアルを構築。
3. **Card & View Layout Styling**:
   - `ScoreManagementView`, `WeeklyQuizView`, `MaterialShareView`, `ForumView`, `MyPageView`, `LoginView` のカード・ボタン・バッジをまるごと祭のクリエイティブ・フェスティバル調へリファイン。
4. **Verification**:
   - `npm run lint` (`tsc --noEmit`)
   - `npm run build`
   - Playwright による実画面キャプチャ検証（未ログイン認証画面、ログイン後メイン画面、定期テスト画面、教材ビューア画面）。
